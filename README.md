# Rejsen hjem

Et lille dansk lærespil for børn med pixel-dyr. Hjælp elefanten Ella med at finde hjem ved at stave til ord, tælle og regne.

- **Stavespil:** "Stav til abe" – find bogstaverne på tastaturet.
- **Regnespil (Ellas tog):** tæl og regn med dyrene i toget.
- Ekstra lege: klæd ud, dyrelyde og lidt engelsk.

Spil det her: https://erta12ab92.github.io/ellas-spil/

Bedst på en computer med tastatur i Chrome. Alt (grafik og stemmer) ligger i `index.html`.
